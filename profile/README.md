## About Zeraynce

Zeraynce designs and develops clean, structured, and scalable software for creative platforms, business workflows, internal tools, and operational systems.

We focus on clarity, maintainability, security, clean design, and long-term product thinking.

## Current Product

### Atelier

Atelier is Zeraynce's current flagship product and is actively in development.

It is a creative management platform for photographers, videographers, studios, organizers, designers, event suppliers, and creative professionals. Atelier helps teams:

- build trusted public profiles
- receive private booking inquiries
- manage confirmed work
- organize project media
- maintain a structured workspace from client discovery to project delivery

## Development Workflow

Zeraynce follows a disciplined GitFlow workflow:

- `main` is for stable, production-ready code
- `develop` is the team checkpoint branch
- all work happens in task branches
- Pull Requests are required
- no direct push to `main`
- specific file staging only
- local testing before pushing
- documentation must be updated when workflow, setup, API, database, infrastructure, or feature behavior changes

Branch types:

- `feat/*`
- `fix/*`
- `refactor/*`
- `docs/*`
- `chore/*`
- `release/*`
- `hotfix/*`

## Repository Standards

Each repository should include:

- clear project documentation
